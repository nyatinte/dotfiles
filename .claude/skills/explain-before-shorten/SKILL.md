# Explain Before Shorten

短くする前に、読み手へ口頭で説明するように意味を組み立てる。明確になった内容を、必要な情報を保って簡潔な日本語にする。

## 手順

1. **伝えることを決める。** 読み手、目的、文体、依頼された範囲を確認し、中心となる要点を一文で整理する。意味を決められない場合は、推測で埋めずに確認する。
2. **いったん説明する。** 「何がどうなるか」「なぜか」「どんな条件・例外があるか」を、必要な範囲で具体的にする。事実、推奨、可能性を区別し、根拠のない情報を足さない。
3. **話題と条件を整える。** 仕組み、条件、例外、注意を分け、条件がどの説明にかかるかを明確にする。重要な用語と制約はその場で分かるように残す。
4. **意味を保って短くする。** 重複や回りくどさを削る。主張、対象、因果、比較、言い切りの強さ、重要な条件を変えない。読みやすさのために必要なら、言葉を削るより話題や構成を絞る。
5. **完成文を確かめる。** 完成文だけを読んでも要点と条件が分かるか確認する。短くしたことで意味が欠けたら必要な説明を戻す。

## Yomiyasuとの併用

日本語の文章を作成・推敲する依頼では、説明の構成と簡潔化を先に行い、利用可能なら `yomiyasu` で最後の日本語推敲を行う。`yomiyasu` の意味保持・不増補の基準を優先し、両スキルの提案が競合したら意味や条件を変えない案を選ぶ。ユーザーが一方だけを指定した場合は、その指定を優先する。

## 出力

通常は完成文を先に示す。下書きや検討過程は求められた場合だけ共有する。編集依頼では指定された正本・範囲だけを変更し、保存や表示を確認できなかった場合はその旨を分けて伝える。
